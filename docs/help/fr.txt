Bienvenue dans Nemoviz Book Reader, un lecteur de livres électroniques prenant en charge plus de quarante-cinq formats et trois types de sortie.

# Configuration système requise

## Configuration minimale

- CPU dual core 1,5 GHz, 2 Go de RAM, 100 Mo de stockage + espace pour la bibliothèque,
- MS Windows 7 SP1 64-bit ou supérieur, .NET Framework 4.8 (sur Windows 7, il doit être installé séparément). Sur cette configuration, vous ne pourrez malheureusement pas utiliser l'OCR ni les voix One Core, car ces deux fonctionnalités ne sont disponibles qu'à partir de Windows 10.

## Configuration optimale

- CPU quad core 2,0 GHz, 8 Go de RAM, 100 Mo d'espace sur SSD + espace pour la bibliothèque,
- MS Windows 10 64-bit 22H2 ou supérieur, .NET Framework 4.8 est intégré.

# Généralités

Nemoviz Book Reader vous permet de lire des documents électroniques sonores et textuels de la manière qui vous convient le mieux. Les formats pris en charge que vous pouvez lire sont :

Formats audio : .mp3, .m4a, .m4b, .wav, .ogg, .oga, .opus, .spx, .flac, .aac, .wma, .ape, .mka, .dsf, .dff, .caf, .aiff, .aif, .ac3, .amr, .weba, .webm, .au et .voc.

Formats texte : .txt, .rtf, .doc, .docx, .odt, .htm, .html, .fb2, .epub, .pdf, .mobi, .azw et .azw3.

Formats spéciaux : Daisy 2.02 audio, Daisy 3 audio, Daisy 2.02 texte, Daisy 3 texte, Daisy 2.02 audio + texte, Daisy 3 audio + texte et epub 3 texte + audio.

Formats braille : .brf, .brl, .bra, .dxb et .i55.

Tous les formats listés peuvent être ouverts directement depuis des archives .7z, .rar et .zip. Nous prenons en charge l'ouverture d'archives multi-volumes ainsi que d'archives protégées par mot de passe, à condition, bien sûr, que vous le connaissiez.

Il est également possible d'ouvrir des formats d'image – les formats contenant des images de texte plutôt que du texte réel, comme un .pdf scanné ou un .epub avec des images de pages. Il est aussi possible d'ouvrir des images standard comme .bmp, .jpg, .tif, etc. Si vous avez par hasard un livre avec de telles images numérotées, vous pouvez également l'ouvrir via Nemoviz Book Reader. Le texte des images sera automatiquement reconnu via Microsoft OCR et, après un court instant, vous obtiendrez un titre lisible sur votre étagère.

Attention ! Tous les formats listés et leurs variantes peuvent être chargés dans Nemoviz Book Reader s'ils ne sont pas protégés par une licence Digital Rights Management. NBR ne peut pas ouvrir les titres protégés par DRM ; si vous en possédez, vous pouvez les lire via le lecteur matériel ou logiciel prévu à cet effet. Pour plus de détails, contactez la source auprès de laquelle vous avez obtenu ces titres.

Tous les types de fichiers de la liste ci-dessus peuvent être lus de manière sonore, visuelle, et même lus en braille si vous disposez de l'équipement nécessaire. Tout ce dont vous avez besoin est un ordinateur compatible Windows, un écran et, si possible, une plage braille configurée avec votre lecteur d'écran.

En plus de tout ce qui a été mentionné, NBR vous permet également de traduire automatiquement des livres en utilisant différents services d'IA LLM. Certains ont des quotas gratuits, d'autres sont payants, mais c'est ainsi que fonctionnent ces services. Nemoviz Book Reader pour Windows est entièrement gratuit, mais les services externes ne sont pas sous notre responsabilité. Nous vous connectons aux services externes via l'application et vous donnons la possibilité d'effectuer le processus de traduction de texte via le lecteur, mais l'inscription aux services, la configuration des moyens de paiement et tout le reste vous incombent. Une fois cela fait, vous devez récupérer une clé API sur le site du service que vous utilisez, la coller dans les paramètres du lecteur à l'endroit prévu, et nous prenons le relais à partir de là.

Nemoviz Book Reader a été testé et est compatible avec les lecteurs d'écran Jaws for Windows et NVDA, mais il devrait fonctionner sans aucun problème avec d'autres. L'accessibilité est le fondement sur lequel cette application a été construite et il ne devrait y avoir aucun problème si vous utilisez un autre lecteur.

Tous les raccourcis clavier sont intégrés dans l'application elle-même et peuvent être utilisés même sans lecteur d'écran. Le lecteur d'écran est là uniquement pour fournir un retour d'information sur ce qui se passe actuellement dans le lecteur et, si vous utilisez le braille, pour transmettre le contenu textuel à la plage braille. Pour tout le reste, vous pouvez utiliser le lecteur sans lecteur d'écran.

Lors de l'importation des formats braille listés ci-dessus, il est important de savoir que NBR utilise la technologie LibLouis avec les tables correspondantes. Nous ne pouvons pas garantir que tout fonctionnera parfaitement pour chaque langue, nous ne pouvons pas effectuer de corrections de tables pour chaque livre individuellement, beaucoup de choses dépendent de la création et de la production des livres eux-mêmes. Si le résultat obtenu après l'importation dans la bibliothèque n'est pas bon, vous pouvez modifier la table braille dans les propriétés du livre si plusieurs sont disponibles pour cette langue. Si cela fonctionne, tant mieux, sinon nous en sommes désolés. Tout ne dépend pas du lecteur, une part de responsabilité incombe également aux éditeurs de livres et aux auteurs des tables braille.

# Premier démarrage

Lors du premier lancement, Nemoviz Book Reader vérifiera si vous souhaitez conserver ou modifier le chemin du dossier de votre future bibliothèque. Gardez à l'esprit que l'emplacement par défaut se trouve dans le dossier utilisateur Windows, généralement situé sur la partition C, qui peut se remplir avec le temps et occuper de l'espace sur le disque système. Si vous le redirigez vers une autre partition ou un autre disque, rien d'essentiel ne changera, et vous aurez la garantie que votre système ne manquera pas d'espace nécessaire à son fonctionnement. De plus, en conservant la bibliothèque sur un autre disque ou une autre partition, vous vous assurez qu'en cas de panne du système, votre collection de livres reste en sécurité.

Ensuite, l'une des deux fenêtres de l'application s'ouvre : la fenêtre de la bibliothèque, qui s'ouvre maintenant après l'installation et chaque fois qu'aucun livre n'est chargé ou que la bibliothèque est vide. Cette fois, nous pouvons la fermer, car il serait judicieux, après l'installation, de parcourir d'abord les paramètres pour configurer ce qui est nécessaire.

# Paramètres

Cette fenêtre se compose de plusieurs onglets ; vous trouverez ci-dessous un aperçu de chacun d'eux. Ce qui la distingue peut-être des autres fenêtres de paramètres, c'est qu'à côté de la plupart des options que vous pouvez y configurer, vous disposez d'un petit bouton d'aide qui ouvre une boîte de dialogue supplémentaire décrivant cette fonction. Vous obtenez de l'aide à chaque étape, et le document que vous lisez actuellement n'a pas besoin de faire 250 pages.

## Général

Le premier élément que nous configurons ici est la langue. Si l'application dispose de la langue de votre système, celle-ci sera déjà sélectionnée et l'interface sera dans cette langue. Sinon, NBR s'affichera en anglais. Si cela ne vous convient pas, ouvrez la liste des langues et choisissez-en une autre.

La deuxième option est le choix de l'emplacement de la bibliothèque. Nous avons déjà abordé cela après le premier lancement. Si vous ne vous étiez pas encore décidé à ce moment-là, c'est l'occasion idéale.

Suivent deux cases à cocher pour activer ou désactiver les fonctions multimédias sur le clavier, si vous en avez. Elles s'appliquent également aux touches des casques. Le premier élément consiste à activer ou non, le second à déterminer si elles fonctionneront globalement ou uniquement lorsque NBR est au premier plan.

Ensuite, une case à cocher permet de choisir si les métadonnées des fichiers seront utilisées dans la bibliothèque ou si les noms des auteurs et des éditions seront affichés à partir du nom du dossier ou du fichier.

Suit la case à cocher *Vérifier automatiquement les mises à jour*. Lorsqu'elle est activée, NBR demande une fois par jour si une version plus récente a été publiée et ne vous avertit que si c'est le cas ; il n'envoie rien sur vous ou vos livres. Si vous la désactivez, NBR ne se connectera pas au réseau de lui-même, et vous pouvez toujours demander une vérification quand vous le souhaitez — dans la bibliothèque, dans le menu Aide, via l'élément *Vérifier les mises à jour*.

Enfin, le choix de l'apparence sous laquelle Nemoviz Book Reader s'affichera. Deux options sont proposées. *Couleurs du système* vous donne un lecteur avec l'apparence classique et la palette de couleurs que vous utilisez dans le système ; c'est également ce que vous obtiendrez si le contraste élevé est activé, car NBR n'applique alors rien de propre et laisse votre schéma s'appliquer entièrement. *Design NBR* propose une apparence du lecteur un peu plus moderne. Si vous n'avez pas fait de choix, NBR décide seul : le contraste élevé obtient Couleurs du système, tout le reste obtient Design NBR.

## Parole et braille

La première option est une série de contrôles pour le choix de la langue et de la voix pour les livres textuels. Nous choisissons la langue, puis la voix pour cette langue. Nous réglons le volume, la vitesse et la hauteur, puis nous confirmons avec le bouton Appliquer. Nous choisissons une autre langue, une voix et d'autres paramètres, et nous appuyons à nouveau sur Appliquer. De cette façon, nous choisissons la voix par défaut pour une langue donnée, et chaque nouveau livre qui s'ouvre, lors de la détermination de la langue dans laquelle il est écrit, reçoit par défaut la voix que nous avons choisie.

Une option peut-être un peu cachée, mais nous n'avions pas de meilleure idée. Dans la zone de liste modifiable pour le choix de la voix, la dernière option est *Ajouter de nouvelles langues*. L'activation de cette option ouvrira une fenêtre dans laquelle vous pourrez choisir une ou plusieurs voix Microsoft One Core et, après confirmation, les installer via le service Windows Update. Cela peut, comme dans le cas de l'ajout de langues pour l'OCR, prendre plus ou moins de temps, selon la charge des serveurs de mise à jour. Il est possible que, selon vos paramètres d'administration, vous receviez également une boîte de dialogue UAC que vous devrez confirmer.

Bien sûr, tous les paramètres mentionnés peuvent être configurés différemment, et ce pour chaque livre individuellement, mais cela se fait dans les propriétés de ce livre ; ici, nous configurons les paramètres généraux.

L'option suivante est le Dictionnaire de prononciation que vous avez sûrement déjà vu. Vous avez la possibilité de corriger la prononciation globalement, par langue et par voix, et pour ces trois choix, vous trouverez les options standard pour ce type de dictionnaire.

Suivent les cases à cocher pour activer et désactiver l'affichage braille et visuel ; chacune d'elles, lorsqu'elle est activée, propose certains paramètres supplémentaires pour lesquels vous trouverez de l'aide sur place. Dans cette version {beta}, ces deux cases sont grisées et portent une note indiquant qu'elles ne sont pas activées ; elles reviendront dans l'une des prochaines versions.

## Périphériques

Ici, vous choisissez la carte son que vous souhaitez utiliser pour écouter des livres. Si vous n'en avez qu'une, vous n'avez rien à modifier car il n'y a pas d'autre choix. Juste après se trouve une case à cocher pour empêcher la mise en veille de la carte son. Si, lors de la lecture de livres, et particulièrement avec des formats texte, vous remarquez des saccades, comme si les phrases ou les paragraphes semblaient tronqués de la première ou des deux premières mots, activez impérativement cette option.

Si vous avez encore un lecteur optique sur votre ordinateur, et peut-être une collection d'anciens livres audio au format CD audio classique, vous pouvez librement activer l'option Utiliser le lecteur optique. Cela active la prise en charge de l'appareil et vous permet de commencer à écouter des livres sur CD.

## Avancé

Sur cet onglet, vous choisissez une ou plusieurs langues qui seront utilisées pour la reconnaissance des documents image lors de l'importation. Nemoviz Book Reader utilise l'outil OCR Microsoft intégré, disponible dans les versions Windows 10 et 11 du système d'exploitation. Il prend actuellement en charge trente-cinq langues dont vous pouvez voir la liste en appuyant sur le bouton *Ajouter une langue*. Lorsque vous sélectionnez les langues souhaitées et appuyez sur Installer, les langues ne seront pas installées immédiatement. NBR ne les installe pas directement, elles sont installées via le service Windows Update et il peut falloir un certain temps avant qu'elles ne soient installées. De plus, selon les paramètres de votre système, il est possible qu'une boîte de dialogue Contrôle de compte d'utilisateur apparaisse, dans laquelle vous devrez confirmer l'installation de la ou des langues.

Après l'installation, et lors de l'importation d'un format image, vous pourrez choisir dans la zone de liste déroulante la langue avec laquelle vous souhaitez reconnaître le texte du titre que vous ouvrez. Cela peut également prendre un court instant, selon la vitesse de la machine et la taille du livre, mais vous pouvez tout suivre sur la barre de progression.

En plus des paramètres de reconnaissance optique, vous pouvez également choisir ici les services LLM pour la traduction. Au moment de la rédaction de ce texte, il y a Google Gemini, DeepSeek, DeepSeek avec un modèle plus grand, trois niveaux d'OpenAI GPT et Microsoft Azure. Comme nous l'avons écrit précédemment, pour ces services, vous avez besoin de clés API ou d'autres types d'autorisation ; vous pouvez en lire plus dans le menu Aide, puis sur l'élément Services et comptes.
Le bouton Règles de traduction ouvrira une fenêtre avec les instructions envoyées aux modèles de traduction afin que ce que vous souhaitez soit traduit avec la meilleure qualité possible. Il existe un ensemble d'instructions qui s'applique à toutes les langues et des ensembles d'instructions pour les langues prises en charge individuellement. Dans cette fenêtre, vous pouvez modifier les instructions existantes et en ajouter pour de nouvelles langues. Lors de la modification des fichiers de règles, ils s'ouvriront dans le Bloc-notes ; en haut du texte, tout ce qui concerne la modification et l'ajout de règles est expliqué.

En plus de la possibilité de traduction, il existe également des voix Cloud supplémentaires ; nous prenons actuellement en charge les voix Google Cloud Chirp 3 et Microsoft Azure Neural. La procédure pour activer ces voix est similaire à celle des services de traduction et vous trouverez plus d'informations à ce sujet dans le menu Aide, puis dans l'élément Services et comptes.

Veuillez noter que ces voix sont également payantes. Google offre gratuitement un million de caractères pour la lecture, ce qui représente environ deux livres moyens de 500 pages. Microsoft en offre moitié moins, 500 000 caractères, ce qui représente environ un livre moyen. Une fois le quota gratuit de caractères épuisé, votre carte bancaire est débitée, et le coût de lecture se situe entre 8,00 $ et 15,00 $ par livre moyen, selon le service.

Pour éviter tout malentendu et toute consommation accidentelle indésirable, nous avons limité la configuration des voix cloud. Dans les paramètres de parole et braille, vous ne verrez pas ces voix et vous ne pourrez pas les définir comme par défaut ; elles ne sont visibles que dans les propriétés du livre sélectionné, mais vous devez d'abord les activer dans les paramètres avancés. Dans les propriétés du livre, vous pouvez choisir l'une de ces voix comme voix par défaut pour un livre spécifique, et cela ne s'applique qu'à ce livre.

Étant donné que les caractères sont consommés lors de l'utilisation des voix cloud même lorsque vous rembobinez, répétez une certaine partie du livre ou consommez des caractères déjà lus d'une autre manière, NBR dispose d'une mémoire temporaire (cache) où est enregistré ce que vous avez lu, de sorte que le rembobinage et les actions similaires ne seront pas traités comme une nouvelle consommation de caractères. Cette option vous permettra également, après avoir lu le livre, de l'exporter au format mp3 et d'obtenir ainsi un livre audio classique.

# Bibliothèque

Cette fenêtre n'est pas visible en permanence ; sauf lors du premier lancement, elle ne s'ouvre qu'en cas de besoin et vous y organisez votre collection de publications électroniques. Vous ajoutez individuellement ou par lots, supprimez, marquez les livres comme lus, non lus ou favoris. Vous pouvez trier l'ordre d'affichage selon plusieurs critères, filtrer les titres par statut (lu, non lu...), et effectuer des recherches.

Pour chaque titre de la bibliothèque, en appuyant simplement sur la touche Tab, vous pouvez également lire les détails sur ce titre. Le titre et l'auteur, l'éditeur et le format, où vous vous êtes arrêté, quel pourcentage du livre vous avez lu, combien de temps il vous reste et d'autres informations. Si possible, vous obtiendrez également une brève description du livre.

## Ajout de titres

Dans le menu déroulant Fichier, vous trouverez deux éléments : Ouvrir un fichier (Ctrl + O) et Ouvrir un dossier (Ctrl + Shift + O). Si vous avez activé la prise en charge du lecteur optique dans les Paramètres, vous trouverez également l'option Ouvrir un CD audio. En plus de cela, il existe aussi une option pour la reconnaissance optique répétée d'un titre sous forme d'image, une option pour créer un livre audio et une option de traduction. Il y a également un élément à ne pas toucher sauf si nécessaire, *Vider la bibliothèque*. Son nom indique clairement ce qu'il fait et, après activation, vous recevrez un avertissement supplémentaire. Si vous confirmez jusqu'au bout, votre bibliothèque sera effacée, toutes les données sur les signets et votre position de lecture seront supprimées, ainsi que les paramètres de langue et de vitesse pour les livres que vous possédez. Par conséquent, évitez cet élément à moins d'être absolument certain de vouloir vider la bibliothèque.
L'option Ouvrir le dossier de la bibliothèque ouvre l'emplacement de votre collection dans l'Explorateur de fichiers.

Avec la première option, vous pouvez ouvrir un fichier individuel (livre MP3 dans un seul fichier, document EPUB ou fichier ncc.html pour un titre Daisy), et avec l'ouverture de dossier, vous pouvez ouvrir un livre audio composé de plusieurs fichiers situés dans un seul dossier. De plus, si vous utilisez l'ouverture de dossier, vous pouvez également importer une plus grande quantité de fichiers différents, c'est-à-dire une collection de plusieurs titres. Nemoviz Book Reader intègre certaines règles de tri et fera de son mieux pour classer et organiser un tel dossier aussi bien que possible.

Ouvrir un CD audio lancera la lecture du livre depuis votre lecteur optique et vous ramènera à la fenêtre du lecteur. L'utilisation d'un CD classique n'importe pas le livre dans la bibliothèque, elle vous permet seulement de le lire via Nemoviz Book Reader.

En plus des fichiers classiques, NBR peut, contrairement à la grande majorité des applications de ce type, ouvrir des fichiers compressés, appelés archives. Parmi les formats d'archives pris en charge, on trouve .zip, .rar et .7z, et en plus des archives en une seule partie, il est possible d'ouvrir des archives multi-parties ainsi que des archives protégées par mot de passe, à condition que vous connaissiez ce mot de passe.

En d'autres termes, peu importe d'où et de quelle manière vous obtenez un livre, dans un fichier standard ou plusieurs, compressé dans une archive ou non, vous pouvez l'importer dans la bibliothèque sans aucune préparation préalable et depuis son emplacement actuel. Nemoviz Book Reader copie les fichiers que vous avez ouverts dans le dossier de la bibliothèque à l'emplacement prévu à cet effet, décompresse les archives et les enregistre dans la bibliothèque sous forme standard, tout en notant toutes les données essentielles sur les titres importés. Vos fichiers sources restent intacts aux emplacements où vous les conservez ; tout ce qui arrive aux livres par la suite se produit sur les copies NBR dans le dossier de la bibliothèque.

L'option pour l'OCR répété sert à refaire la reconnaissance optique d'un titre sous forme d'image avec une autre langue si vous n'êtes pas satisfait du résultat de la reconnaissance lors de l'ouverture du livre.

L'option Traduire le livre ouvre une boîte de dialogue dans laquelle vous choisissez la langue source, la langue vers laquelle vous souhaitez traduire le livre, le ou les services que vous souhaitez utiliser, ainsi qu'un champ où vous pouvez saisir quelques instructions de base sur quoi et comment traduire.

L'option Exporter en tant que livre audio fait exactement ce que son nom indique. Que vous utilisiez l'un des synthétiseurs vocaux installés ou des voix dans le cloud, vous pouvez transformer un livre textuel en livre audio et l'exporter vers l'emplacement souhaité. Le livre est exporté sous forme d'un seul fichier .mp3, les paramètres sont identiques à ceux du TTS que vous utilisez et la qualité de l'enregistrement sera égale à la qualité de l'écoute en direct. Avant de commencer, NBR vous demandera une confirmation et vous indiquera combien de temps la création devrait prendre.

## Étagère à livres

Pendant que vous vous déplacez avec les flèches haut ou bas sur l'étagère à livres, qui est le nom de la partie de la fenêtre de la bibliothèque où se trouve la liste de vos titres, vous entendrez les titres que vous avez dans la bibliothèque. La façon dont le titre du document sera prononcé dépend de plusieurs choses. Lors de l'importation, NBR tente d'extraire le nom de l'auteur, le titre de l'œuvre et quelques autres données des métadonnées du fichier contenant le livre. Si ces données n'existent pas, NBR nommera le livre selon le nom du dossier ou du fichier.

Si aucune de ces présentations ne vous convient, dans le menu contextuel du titre du livre ou, plus simplement, avec la touche F2, vous pouvez renommer le livre sélectionné comme vous le souhaitez. Lors du renommage, vous trouverez deux champs séparés pour le nom de l'auteur et le titre de l'œuvre, et une fois saisis, confirmez l'entrée avec la touche de confirmation ou appuyez simplement sur Enter.

En plus des données de base sur le livre comme le nom de l'auteur et le titre de l'œuvre, en vous déplaçant avec les flèches dans cette liste, vous pourrez entendre le statut du livre : *En cours de lecture*, *En lecture*, *Lu* et *Non lu*. Si vous avez marqué un titre comme favori, vous l'entendrez également. Dans le menu contextuel, où se trouve l'élément de renommage déjà mentionné, vous pouvez également trouver les éléments Marquer comme lu, Marquer comme non lu, Marquer comme favori, Supprimer et Propriétés, mais nous en parlerons un peu plus tard.

Une fois arrêté sur un titre, vous pouvez utiliser la touche Tab pour accéder à une section où, à l'aide des flèches haut et bas, vous obtiendrez de nombreuses informations sur le livre, notamment l'endroit où vous vous êtes arrêté, le pourcentage du livre lu et restant, la durée, le lieu d'édition et de production, les données techniques de l'enregistrement sonore, etc. Ces données dépendent du format du livre et varient d'un titre à l'autre.

En continuant à naviguer dans la fenêtre de la bibliothèque, vous arriverez à un champ de recherche qui fonctionne selon un principe simple : il recherche la chaîne de caractères saisie dans les noms des éléments présents sur l'étagère. Si vous tapez « ana », il trouvera certainement les auteures nommées Ana, mais il trouvera aussi 7000 jours en Sibérie.

Après le champ de recherche, il y a une zone de liste modifiable de filtre où vous pouvez déterminer quels livres doivent être affichés. Par défaut, tous les livres sont toujours présents, mais vous pouvez basculer le filtre sur En cours de lecture, Non lu, Lu et Favori, et l'affichage sur l'étagère sera mis à jour selon votre choix.

## Tri

Dans ce menu, vous ne trouverez que les options habituelles que vous avez déjà vues un nombre incalculable de fois. Vous pouvez choisir l'ordre d'affichage des titres dans la bibliothèque : par ordre alphabétique, par date d'ajout, par format et par statut. Le statut signifie non lu, lu, etc. Chacun de ces choix peut être affiché par ordre croissant ou décroissant.

Une fois familiarisé avec le contenu et les fonctions de la fenêtre de la bibliothèque, il est temps de choisir un livre sur l'étagère et de naviguer avec Tab jusqu'au bouton Charger ou, plus simplement, d'appuyer sur Enter alors que vous êtes sur le titre. Le livre que vous avez choisi de lire sera toujours au-dessus de l'étagère, dans une section séparée intitulée Lecture en cours. Il convient de noter que le livre que vous lisez, c'est-à-dire le livre actif chargé dans le lecteur, ne peut pas être supprimé comme les autres livres de l'étagère. Vous devez marquer le livre actif comme lu via le menu contextuel pour qu'il passe du mode Lecture en cours au mode Lu, et ce n'est qu'alors que vous pourrez le supprimer.

En résumé, lorsque vous appuyez sur Enter sur le titre d'un livre ou sur le bouton Charger, la bibliothèque se ferme et vous revenez à la fenêtre principale du lecteur.

# Lecteur

Cette fenêtre est toujours visible sur l'écran de votre ordinateur ; parfois elle est masquée par la fenêtre de la bibliothèque, parfois par la zone de lecture de texte, mais c'est en fait la fenêtre principale où vous gérez le livre après son chargement. Vous pouvez naviguer dans la fenêtre du lecteur avec Tab comme dans n'importe quelle autre fenêtre et activer certains éléments avec la touche Enter. Cependant, contrairement aux autres fenêtres de l'application et d'autres logiciels, les touches fléchées et la barre d'espace sont réservées à d'autres fonctions. Ainsi, si vous arrivez par exemple sur le bouton des signets avec Tab, vous ne pourrez pas l'activer avec la barre d'espace ; vous devrez impérativement utiliser la touche Enter.

Dans la ligne Tab, sans ordre particulier, se trouvent les boutons et fonctions suivants sur la fenêtre principale du lecteur :

| Lecture/Pause | barre d'espace |
| Avancer | Shift + droite |
| Reculer | Shift + gauche |
| Volume | F11 et F12 |
| Vitesse | Ctrl + gauche et Ctrl + droite |
| Progression de l'écoute | flèches gauche et droite |
| Pas de navigation | Shift + flèches haut et bas |
| Bibliothèque | F3 |
| Paramètres | F2 |
| Propriétés | Alt + Enter |
| Marquer | F5 |
| Signets | F6 |
| Aller à… | F4 |
| Aide | F1 |
| Compteur | F7 |
| Champ d'information | F8 |

Dans le champ d'information, vous pouvez obtenir des données de base sur la lecture telles que l'auteur, le titre, le temps écoulé, la page et quelques autres détails, selon le format du livre que vous lisez. Une pression sur F8 lira simplement le contenu de l'écran d'information, et une double pression placera le focus sur le lecteur d'écran, vous permettant de lire plus en détail ce qui est écrit à l'aide des flèches.
Avec la touche F10, vous pouvez connaître le temps écoulé du titre que vous lisez, et par une double pression rapide sur F10, vous entendrez le temps restant.

Toutes les touches ont leurs propres raccourcis clavier afin que vous puissiez y accéder facilement sans trop naviguer dans la fenêtre, et la gestion du livre que vous lisez est plus que simple.

## Menu contextuel

Tout ce que le lecteur peut offrir se trouve également dans le menu contextuel, vous pouvez donc accéder à chaque fonction sans avoir à mémoriser les raccourcis. Vous l'ouvrez avec la touche Applications, la combinaison Shift + F10 ou un clic droit de la souris. Les éléments sont classés dans des sous-menus, et chaque élément affiche son raccourci, de sorte que le menu sert également de rappel des touches.

- Lecture : lecture et pause, avance et retour, volume et vitesse.
- Fichier : ouvrir un fichier, ouvrir un dossier et, si vous avez un lecteur optique, ouvrir un CD audio.
- Livre : marquer comme lu, ajouter aux favoris, traduire, exporter en livre audio et propriétés.
- Options : paramètres, bibliothèque, ouvrir le dossier de la bibliothèque, aller à, signets et compteur.
- Aide : manuel, nouveautés, services et comptes, vérifier les mises à jour, exporter le rapport et à propos du programme.
- Quitter ferme le programme, identique à Alt + F4.

Le menu appelle exactement les mêmes fonctions que les touches du panneau et se comporte donc de la même manière. Si une action n'est pas possible à ce moment-là, par exemple parce qu'aucun livre n'est chargé, vous entendrez un court signal sonore au lieu que l'élément soit grisé. La seule chose qui ne figure pas dans le menu est la suppression de toute la bibliothèque, car il s'agit de la seule action irréversible du programme et elle reste là où elle était, dans la bibliothèque et après deux confirmations.

## Lecture

- La barre d'espace permet de lancer ou d'arrêter la lecture.
- Les flèches gauche ou droite permettent de « rembobiner » de cinq secondes ou, s'il s'agit d'un livre textuel, de passer à la phrase précédente ou suivante.
- La combinaison des touches Ctrl + flèches gauche ou droite permet de régler la vitesse de lecture.
- Les touches F11 et F12 permettent de régler le volume, F12 pour augmenter et F11 pour diminuer.
- La combinaison des touches Shift + haut ou bas permet de choisir le pas de navigation (titre, chapitre, carte de texte, durées spécifiques), le choix variant selon le format et la structure du livre.
- La combinaison des touches Shift + flèches gauche ou droite permet de se déplacer selon le pas de navigation choisi.

En bref, lancez la lecture du livre choisi avec la barre d'espace, et en maintenant la touche Ctrl enfoncée, utilisez les flèches gauche et droite pour régler la vitesse de lecture.

Si vous souhaitez effectuer un saut rapide en avant ou en arrière, vous pouvez utiliser les flèches gauche ou droite pour avancer ou reculer de cinq secondes ou d'une phrase. Pour des sauts de navigation plus importants, appuyez sur Shift, utilisez les flèches haut et bas pour sélectionner le pas souhaité, puis, tout en maintenant Shift enfoncé, utilisez les flèches gauche et droite pour naviguer dans le livre selon le pas choisi. Lorsque vous souhaitez savoir comment et vers où vous progressez dans la lecture du livre, appuyez à tout moment sur F8 et le lecteur d'écran lira tout le contenu de l'écran d'information. Si vous souhaitez lire le champ d'information plus en détail, élément par élément, appuyez deux fois rapidement sur F8. Une fois terminé, quittez le champ d'information en appuyant à nouveau deux fois sur F8 ou simplement sur Escape pour que les touches fléchées retrouvent leurs fonctions de navigation. Si vous souhaitez entendre le temps écoulé ou restant, appuyez une ou deux fois sur F10.

L'idée derrière cette approche de la navigation était que l'utilisateur n'ait pas à apprendre et à mémoriser une longue série de raccourcis. La majeure partie de la navigation est organisée sur les touches fléchées et, en combinaison avec les touches de modification Shift et Ctrl, il est possible de ne pas avoir à déplacer la main sur le clavier. Placez votre main droite sur les flèches, utilisez la main gauche pour appuyer sur l'un des modificateurs si nécessaire, et c'est toute la philosophie de la navigation. Les plus habiles et les plus débrouillards pourront probablement utiliser le pouce de la main droite pour appuyer sur Ctrl ou Shift sur le côté droit du clavier, mais le mode d'utilisation est laissé au choix de chacun. Tous les autres raccourcis, à l'exception de Alt + Enter pour Propriétés car il s'agit d'une convention Windows habituelle, sont placés sur les touches de fonction, le tout dans le but de simplifier au maximum la gestion.

## Aller à...

Cette commande, comme son nom l'indique, sert à sauter à une partie spécifique du livre en quelques pressions ou clics. Pour les formats non structurés tels que le texte brut, la plupart des formats audio dans un seul fichier ou les livres structurés mal formatés, elle ne peut pas être activée, ce qui est confirmé par un signal sonore. Pour les livres avec une structure correcte, vous pourrez sauter aux chapitres, sous-chapitres et autres segments structurels du livre. Bien sûr, tout dépend de la façon dont les producteurs ont défini la structure dans le livre lui-même. En plus de ce qui précède, cette boîte de dialogue dispose également d'un groupe spécial pour sauter à une page, si le livre en contient. Après l'ouverture, il y a d'abord la liste des parties mentionnées précédemment, une pression sur Tab vous amènera au saut de page, s'il y en a. Dans le champ qui s'affichera, le numéro de la page où vous vous trouvez actuellement est déjà inscrit. Saisissez le numéro de page souhaité et appuyez sur Enter pour sauter.

## Signets

Deux touches qui vont par paire – Marquer pour placer un signet et Signets où vous pouvez gérer les signets placés. Lors de la pose d'un signet, vous entendrez également un court signal sonore afin d'être sûr qu'il est bien placé. Dans la gestion des signets, vous pouvez vous déplacer parmi eux avec les flèches et appuyer sur Enter pour sauter à la position du signet. De plus, vous pouvez supprimer ceux dont vous n'avez pas besoin. Pour les livres audio, seul le temps est affiché pour l'instant, et pour les livres textuels, le début de la phrase où vous avez placé le signet. Si vous n'avez pas de signets placés, la touche Signets ne peut pas être activée, ce qui vous sera également indiqué par un signal sonore.

## Minuteur

Un minuteur de mise en veille classique, rien de complexe. Vous choisissez le temps, 15, 30, 45 et 60 minutes sont proposées comme options, l'option suivante est personnalisée avec 90 minutes par défaut, mais vous pouvez changer cela pour n'importe quelle valeur souhaitée. Suit le choix de ce qui se passe après l'expiration du compte à rebours, où sont proposés : Arrêter la lecture, Arrêter et fermer l'application et Arrêter et éteindre l'ordinateur.

De plus, il y a une case à cocher qui vous demande si vous souhaitez placer un signet au début du compte à rebours. Cela peut être utile pour revenir au moment où vous n'étiez pas encore endormi et trouver plus facilement l'endroit où vous vous êtes arrêté de lire.

Le compte à rebours commence en appuyant sur le bouton *Démarrer*, la boîte de dialogue se ferme, et au lieu du nom Minuteur sur la fenêtre du lecteur, le compte à rebours actif est maintenant visible. Si vous réactivez l'option Minuteur, le compte à rebours est annulé et vous pouvez choisir une nouvelle heure dans la boîte de dialogue ou tout annuler avec le bouton prévu à cet effet.

La lecture est arrêtée par deux boîtes de dialogue : Signets et Minuteur. Lorsque vous avez fait ce que vous vouliez dans celles-ci et que vous confirmez en retournant à la fenêtre du lecteur, la lecture continue. Paramètres, Bibliothèque, Aller à et Propriétés laissent le livre continuer à jouer — dans le cas de Propriétés, c'est intentionnel, car vous y réglez des choses que vous souhaitez entendre pendant que vous le faites.

Quelques mots également sur les commandes de vitesse et de volume. Le volume est sur les touches F11 et F12 — F12 augmente, F11 diminue — par paliers de 5%, et lorsque vous atteignez la fin, vous entendez un signal sonore. La vitesse varie par paliers de 0,1x, de 0,5x à 3x, et ce, de la même manière pour les livres audio et textuels. La seule différence est que 1x pour un livre audio signifie la vitesse de l'enregistrement, et pour un livre textuel, la vitesse à laquelle la voix choisie parle par elle-même. Vous entendrez un signal sonore lorsque vous dépasserez la vitesse normale, ou pour le texte, celle définie pour cette voix.

Ce qui est le plus important pour vous en tant qu'utilisateur, c'est que Nemoviz Book Reader mémorise absolument tout ce qui concerne la lecture des livres que vous écoutez. Sont mémorisés la position, le volume, la vitesse pour les livres audio, ainsi que le type, la vitesse, la langue et la hauteur de la synthèse vocale (TTS) pour les livres textuels ; les paramètres de traitement audio sont mémorisés pour les livres audio, tout comme les paramètres d'affichage braille et visuel pour les livres textuels. En d'autres termes, tout ce que vous avez configuré selon vos souhaits et besoins est mémorisé séparément pour chaque livre.

# Propriétés

Comme cela a déjà été mentionné à plusieurs reprises, les paramètres et réglages pour chaque livre sont déterminés individuellement dans les propriétés du livre. Les livres audio ont leurs propres propriétés, les livres textuels les leurs, et les livres spéciaux comme Daisy audio + texte possèdent les deux, sur deux onglets distincts dans la fenêtre des propriétés. Vous pouvez ouvrir les propriétés depuis la fenêtre du lecteur avec le bouton Propriétés ou le raccourci Alt + Enter, depuis la fenêtre de la bibliothèque lorsque vous êtes sur le titre du livre via le menu contextuel, ou également avec le raccourci Alt + Enter.

## Propriétés sonores

Lorsque vous ouvrez Propriétés, vous remarquerez d'abord la case à cocher Traitement sonore. Vous n'avez pas besoin de l'activer si le son du livre que vous écoutez est acceptable, mais si ce n'est pas le cas, l'activation de Traitement sonore pourrait vous permettre d'obtenir un son audible. Cocher la case lance l'analyse de l'enregistrement sonore du livre, ce qui peut prendre entre trente secondes et quelques minutes, selon la vitesse de votre machine. Grâce à la barre de progression, vous pouvez voir à tout moment l'état de l'analyse et le temps restant. Une fois l'analyse terminée, Nemoviz Book Reader réglera les filtres ci-dessous sur un état optimal. Si le son vous convient, validez simplement avec OK ; si vous pensez pouvoir encore l'améliorer, voici une brève description de ce qui peut être fait.

Il y a neuf filtres qui vous aideront ou non à améliorer quelque peu le son des livres audio sur des enregistrements anciens et/ou de mauvaise qualité. Chaque contrôle peut être activé ou désactivé individuellement, vous n'avez donc pas besoin de tous les utiliser en même temps. Lorsque vous activez Traitement sonore, vous trouverez d'abord le bouton Annuler, qui ramène tous les filtres à leurs paramètres par défaut. Vient ensuite la case à cocher Contourner, dont l'activation et la désactivation vous permettent d'entendre instantanément la différence entre l'original et vos réglages. Le raccourci pour le contournement est Ctrl + B, afin que vous n'ayez pas à revenir constamment des contrôles au contournement et inversement.

Le premier groupe est Clics et grondements avec deux contrôles : Supprimer les clics corrige les craquements et les clics sur les vieux enregistrements — il ne les atténue pas, mais trouve les échantillons endommagés et les restaure à partir de ce qui les entoure — et Supprimer les grondements, appelé Hi Pass, élimine les bruits dans le spectre bas de l'enregistrement, des appareils électriques aux chocs accidentels sur le microphone ou la table. Suit Réduction du bruit, prévu pour le souffle de la bande, les mauvais microphones et les bruits similaires dans un spectre de fréquences un peu plus élevé. Adoucir les sibilances réduit les sons explosifs comme C, S, Ch et similaires qui ont été déformés sur l'enregistrement en raison d'un enregistrement trop proche ou de hautes fréquences accentuées. Le groupe Voix et ambiance comporte également deux contrôles : Égaliser la parole tente d'égaliser les parties plus silencieuses et plus fortes de l'enregistrement, et Corriger l'acoustique atténue cette tonalité basse sur laquelle l'enregistrement résonne dans une petite pièce dure, et ce uniquement lorsqu'elle est trop forte. Ensuite, il y a Tonalité, un égaliseur à cinq bandes ; les bandes sont marquées par leurs fréquences — 200, 800, 1.8k, 3.5k et 5k+ — et la dernière est une étagère, ce qui signifie qu'elle augmente ou diminue tout ce qui est au-dessus d'elle, pas seulement une zone. Enfin, il y a le groupe Intensité sonore et pauses avec deux contrôles : Intensité sonore automatique (normalisation) augmente l'enregistrement global au niveau maximal sans distorsion, et Bruit dans les pauses (gate) élimine les bruits restants dans les espaces entre les phrases.

Chaque filtre dispose de cinq niveaux d'action : minimal, léger, moyen, fort et maximal. Il convient également de répéter que chacun peut être activé ou désactivé individuellement.

Le Traitement sonore est également mémorisé pour chaque livre séparément.

Il est important de noter que ce traitement sonore ne fera pas de miracles et que vous n'obtiendrez pas, à partir d'un mauvais enregistrement des années soixante du siècle dernier, une voix cristalline et claire comme si elle avait été enregistrée dans les studios Abbey Road à Londres, mais cela vous permettra, nous l'espérons, d'arriver au bout du livre sans devenir fou à cause de la mauvaise qualité.

## Propriétés du texte

Tout comme dans les paramètres de parole, vous avez ici le choix de la langue, de la voix, de la vitesse, du volume et de la hauteur pour le livre sélectionné. Dans les Paramètres, vous choisissez les valeurs par défaut pour tout, ici vous les réglez pour un titre spécifique. Si vous vous demandez pourquoi, l'exemple le plus simple est si la voix par défaut dans les paramètres est masculine, et que vous souhaitez lire un roman écrit dans une perspective féminine avec une voix féminine, vous modifiez cela dans les propriétés du texte spécifiquement pour ce livre. Tous les autres livres dans cette langue continueront de s'ouvrir par défaut avec la voix masculine, tant que vous ne le modifiez pas. De plus, vous pouvez lire sans problème une lecture facile à 1,5x, mais pour quelque chose de plus difficile sur lequel vous devez réfléchir en cours de route, vous préférerez peut-être revenir à 1x ou plus lentement.

Il n'y a pas de dictionnaire de prononciation ici, suivent les paramètres pour le braille et les paramètres visuels. Si vous activez l'affichage visuel, vous obtenez un choix sur la manière dont le texte sera affiché sur votre écran. Si vous souhaitez lire uniquement en braille ou visuellement sans parole, choisissez cette option dans la liste des voix. Dans cette version {beta}, la sortie braille et visuelle est grisée et porte une mention indiquant qu'elles ne sont pas activées.

Nemoviz Book Reader ne possède pas de table braille de sortie et n'en aura pas. Ce qui s'affiche sur la plage braille est traduit par le lecteur d'écran, via la table définie dans ses propres paramètres, et c'est le seul endroit approprié pour ce choix — deux tables pour une même ligne ne pourraient que créer des conflits. La seule table braille dans Nemoviz Book Reader est la table *d'entrée* : celle utilisée pour lire le fichier .brf lors de l'importation, et vous pouvez la modifier dans le groupe Source braille, qui n'apparaît que pour les livres provenant d'un tel fichier. Ce groupe fonctionne également dans cette version {beta}.

## Paramètres d'affichage visuel {beta}

Selon votre choix dans Paramètres ou Propriétés, vous verrez à l'écran un petit cadre au-dessus de l'interface du lecteur dans lequel le texte défilera comme des sous-titres de films ou de séries étrangères. Si vous choisissez l'une des deux autres options, le cadre sera plus grand et le texte défilera à l'écran comme un générique de fin ou changera cadre par cadre. Dans ces deux affichages, la ligne prononcée est affichée dans une couleur différente.

En bas du cadre, vous pouvez modifier la police, la taille et d'autres paramètres d'affichage, et vous disposez également des touches de base pour contrôler la lecture. Tous les raccourcis clavier fonctionnent également dans ce cadre.

Si vous avez choisi d'utiliser le braille, le petit cadre décrit en premier apparaîtra, car le braille ne peut pas fonctionner sans l'affichage du texte transmis au lecteur d'écran. Si vous choisissez uniquement l'affichage visuel, vous avez le choix du type d'affichage. Dans les deux cas, l'affichage apparaîtra après le lancement de la lecture. Si vous n'avez sélectionné aucune de ces options et que vous souhaitez seulement écouter, ou si vous êtes curieux de voir à quoi cela ressemble, vous pouvez toujours activer ou désactiver l'affichage depuis la fenêtre du lecteur avec la touche F9.

C'est à peu près tout en ce qui concerne le document d'aide. Vous trouverez des explications plus détaillées à côté des contrôles là où c'est nécessaire, via le petit bouton avec un point d'interrogation ou la touche F1 dans le groupe sélectionné. Merci d'avoir été patient et d'être arrivé à la fin du texte. En guise de petite attention, vous avez maintenant l'opportunité de découvrir deux fonctions cachées.

# Pour les plus persévérants

La première fonction est l'ajout alternatif d'un ou plusieurs titres à la bibliothèque. Au lieu de passer par les boîtes de dialogue Ouvrir un fichier et Ouvrir un dossier décrites précédemment, copiez simplement le contenu souhaité dans le dossier de la bibliothèque via Windows ou l'Explorateur de fichiers. Au prochain démarrage, Nemoviz Book Reader actualisera la bibliothèque et affichera les nouveaux titres. S'il est déjà lancé, appuyez simplement sur la touche Actualiser dans la fenêtre de la bibliothèque.

La deuxième fonction cachée est liée à la navigation. En plus de tout ce qui a été décrit ci-dessus, vous pouvez vous déplacer dans le livre que vous lisez avec les raccourcis clavier de Ctrl + 1 à Ctrl + 9, qui vous placent respectivement à 10, 20, jusqu'à 90 % du livre.
