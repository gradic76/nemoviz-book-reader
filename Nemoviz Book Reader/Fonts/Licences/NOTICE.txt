FONTS BUNDLED WITH NEMOVIZ BOOK READER
======================================

NBR ships five type families for its reading window. They are loaded PRIVATELY,
into this process only, and are never installed into Windows: NBR is portable
and has no business changing the machine it runs from.

Every copyright line below was read out of the font file's own name table
(name IDs 0, 1 and 14) rather than copied from a download page, so it says what
the shipped binary says.

Full licence texts accompany this file: OFL-1.1.txt and CC-BY-4.0.txt.

NONE OF THESE FONTS HAVE BEEN MODIFIED. They are shipped byte for byte as
published, which keeps the Reserved Font Name clauses satisfied without further
thought: an OFL Reserved Font Name only binds a MODIFIED version.
