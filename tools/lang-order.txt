# The order every .lang file is written in — one definition, three files.
#
# WHY THIS EXISTS. Gordan, 2026-08-22: "neke stvari se pojavljuju par stotina
# linija ispod kad već pomisliš da si završio s njima." The files had grown by
# accretion, so a translator met the same window three times in three places and
# never knew when a window was finished. Here the file walks the PROGRAM: the
# player and its panel, then each window in turn, and inside a window the thing
# itself before the dialogs it opens.
#
# HOW IT IS READ. A line starting with = opens a section and becomes a comment
# header in the output. Every other line is a key PREFIX; each takes all keys
# that begin with it and are not already placed, in the order they are listed
# here first and alphabetically after that. A key nobody claims lands under
# "everything else" at the foot, which is the signal to add it here.
#
# tools/lang-reorder.pl applies it. Run it on all three files together or they
# stop matching, which is the one thing this file exists to prevent.
